# Superseded P2 Flow Candidate

The former active changeset `002-p2-system-ruleview-access.yaml` described the
Guard, permission, runtime owner and protected-access model. It was never
archived into the project-level flow baseline.

The project decision to favor direct business use retired that candidate before
archive. Its exact historical content remains available from Git revision
`8b362d5dc5b324104585ac41db77f4c42544c5ee`.

The replacement is `../changes/004-p2-simple-runtime-model.yaml`, based directly
on the stable `FLOW-R02@compiler-owned-discovery` baseline.
